## 后续训练前需要核实

1. **损失汇总**：模型已返回三个坐标损失，又返回它们均值乘权重的 `loss_uncert_xyz`；训练循环将全部损失求和。这会额外增加坐标项贡献，需要确认是否符合原设计。本次未更改损失定义。
2. **训练步数**：零件配置设置了 `SOLVER.MAX_ITER`，当前训练循环仍使用 `TOTAL_EPOCHS * iters_per_epoch` 计算总步数，不能仅凭配置注释判断实际训练长度。配置中的旧注释与部分数值也不一致。
3. **精度与兼容性**：快照广泛调整了 NumPy dtype；OpenGL 缓冲区、模型输入 dtype 和依赖版本仍需实际验证。部分上游旧 NumPy API 仍存在，不宣称已全面适配 NumPy 2。
4. **数据与评测协议**：零件数据的单位、自动扩展训练索引的行为、XYZ 坐标系以及区域监督关闭的影响仍需结合实际数据核验。当前没有据此报告精度改善。
